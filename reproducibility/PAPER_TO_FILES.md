# Paper-to-file-to-command map

Table and figure numbers refer to the English JPA manuscript after the 2026-10-14 minor revision. Run commands from this package's root. Every `reproductions/...` directory below must be new.

| Paper item | Data / implementation | Reproduction command and comparison |
|---|---|---|
| Table 2 and the two paired ratios in section 6 | The exact 96 inputs are in `TABLE_2_AND_5_TRAJECTORIES.csv`: N=256, U=2, W=0.04; ungapped variance, f=0.8 variance, f=0.8 passband; seeds 100000--100031. They come from `results/confirmation/20261013T071254Z/` and `20261013T071820Z/`. Frozen aggregate: `results/analysis/20261013T071959Z/summary.json`; code: `analyze_confirmation.py`. | `python reproduce.py --target tables --output reproductions/tables`; compares 41 groups, 10 paired comparisons and three endpoint branches against frozen results (rtol 1e-10, atol 1e-12). |
| Table 5; a/p, a/surrogate and p/c diagnostics | Same 96 rows; predictions are matched by `(n,U,W,f,normalization,seed)` in `results/sample_diagnostic/20261013T072213Z/summary.json`, with `modes_N256_U2.0.npz`. Saved comparisons: `results/reanalysis/summary.json`, `group_estimates.csv`, `per_seed_estimates.csv`; code: `tools/reanalyze_existing_data.py`. | `python reproduce.py --target posthoc --output reproductions/posthoc`; uses all 752 saved confirmation trajectories and all 123 group/window combinations to preserve the original bootstrap sequence; compares the saved summary. |
| Figure 1 | `figures/data/01_boundaries.csv`, `01_phase_grid.npz`, `01_rates.csv`; code: `figures/make_manuscript_figures.py`. | `python reproduce.py --target figures --output reproductions/figures`; redraws in the output directory, leaving supplied figures untouched. |
| Figure 2 and proposition 3 | `figures/data/03_endpoints.csv`; the same figure script. Original coefficient implementation: `tools/check_closed_kernel.py`, with `results/theory_audit/closed_kernel_initial.json`. | `python reproduce.py --target figures --output reproductions/figures_again`; coefficient regeneration is also included in the `tables` target. |
| Table 4: 25 open-point kernel/resolvent comparison | `checks/verify_manuscript.py`, `checks/results/20261014_v1/summary.json` and manifest. | `python checks/verify_manuscript.py --output reproductions/kernel_25`; the original PASS label only records successful execution. The `checks` target additionally checks 25 rows and maximum relative error below 7e-5. |
| Table 4: three worst points, broadening and chain length | `checks/refine_resolvent.py`, `checks/results/20261014_jpa_refinement/`; selection uses the saved original 25-point run. | `python checks/refine_resolvent.py --output reproductions/refinement`; this checks resolution of selected existing points, not a uniform parameter-domain bound. |
| Table 4: Fock construction, exchange symmetry, continuum completeness | `tools/audit_core_structure.py`, `results/core_review/20261013T084025Z/checks.json`, `tests/`. | Structural audit runs inside the isolated `tables` target; `python -m unittest discover -s tests -v` runs the 24 original tests. |
| Appendix C.4: infinite-chain finite-time window | `tools/infinite_chain_finite_time.py`, `configs/infinite_chain_finite_time_v1.json`, `results/infinite_chain_finite_time/20261013_render_repair/`. | `python tools/infinite_chain_finite_time.py --output reproductions/window`; no finite-ring dynamics are generated. |
| Appendix D: higher-order momentum support | `tools/check_momentum_support.py`, `results/kinematic_support/support_check.json`. | `python tools/check_momentum_support.py --output reproductions/support`; checks allowed momentum support, not a nonzero higher-order rate. |
| Recompute the saved dynamics from seeds (optional, not a default check) | `run_confirmation.py`, `run_window_pilot.py`, `run_leakage.py`, `src/`, `configs/confirmation_v1.json`, `configs/confirmation_v1_batch2.json`, and the frozen protocols. | `python REPRODUCE_RESEARCH.py`; creates an isolated source snapshot and reruns the original seeds. Its expense is separate from the default saved-data reproduction. |

The default `all` target runs `tables`, `posthoc`, `checks` and `figures`. It does not invoke the last row. No reproduction target establishes priority over all literature or a finite-W lifetime.
